# Изменения

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/). Номер текущей версии — в `kit/VERSION`, у каждой версии есть git-тег `vX.Y.Z`. [English](CHANGELOG.en.md)

Версии до 1.0.0 проставлены задним числом по истории коммитов.

## [Не выпущено]

### Добавлено
- Удаление Flint VPN: `uninstall.ps1` / `uninstall.sh` (на роутере — `kit/uninstall.sh`). Перед удалением делается бэкап; сеть, Wi‑Fi и прошивка остаются, устройства ходят в интернет напрямую.

- Скриншоты в README пересняты под текущий дизайн, добавлены вкладки DNS и «Настройки».

## [1.7.1] — 2026-10-04

### Изменено

## [1.7.0] — 2026-10-04

### Добавлено
- Режимы DNS на новой вкладке панели «DNS» и в `flint-dns`: DoH (по умолчанию, как раньше), DNSCrypt и обычный DNS по UDP. У каждого режима свой сервер, переключение режима его не сбрасывает.
  - DNSCrypt: AdGuard DNS (с фильтрацией и без), Quad9 (с фильтрацией и без), dnscry.pt (Москва, Стокгольм) или свой stamp `sdns://…`. Запасной вариант, если в сети блокируют DoH.
  - UDP: Cloudflare, Google, Quad9, AdGuard DNS, Яндекс, DNS основного роутера или свои IP-адреса. В этом режиме dnscrypt-proxy остановлен.
- Новый DNS проверяется; если он не ответил за 15 секунд, возвращается прежний.

### Изменено
- Настройки DNS переехали из «Настроек» на вкладку «DNS»; ссылка на DNS со «Статуса» ведёт туда же.
- Upstream dnsmasq задаёт `flint-dns`, а не установщик: выбранный режим переживает повторный деплой.

## [1.6.0] — 2026-10-04

### Добавлено
- Выбор DNS-сервера (DoH) в панели («Настройки → DNS-сервер») и командой `flint-dns`: Cloudflare (по умолчанию, как раньше), Google, Quad9, AdGuard DNS или свой адрес `https://…`. Новый сервер проверяется; если он не ответил, остаётся прежний. Выбор переживает повторный деплой и входит в файл настроек.
- «Статус»: кроме IP через VPN показывается IP провайдера (до VPN); там же — текущий DNS-сервер.

### Изменено
- Конфиг dnscrypt-proxy (`/etc/dnscrypt-proxy2/flint-doh.toml`) теперь собирает `flint-dns`, а не копирует установщик.
- README: смена PIN, перенос настроек файлом, «Сайты без блокировки» и «Недавно заблокировано», закрепление адресов устройств основной сети, новые строки в «Решении проблем».

## [1.5.0] — 2026-10-04

### Добавлено
- Вкладка «Настройки»: экспорт настроек в файл и импорт из файла (работает и с телефона). В файл входят подписки, свои и ручные серверы, сайты, блокировка рекламы, режимы и интервалы; PIN и сеть (`flint.env`) не входят, поэтому файл подходит и для другого Flint. Импорт заменяет эти настройки и сразу применяет их, прежние остаются в `/tmp/flint-settings-prev.txt` до перезагрузки.
- Команда `flint-settings export` / `flint-settings import [файл]`.

### Исправлено
- Сценарии тестов не запускаются одновременно (блокировка `/tmp/flint-test.lock`), у каждого свой снимок `/etc/xray`; без снимка `/etc/xray` не удаляется. Раньше два параллельных прогона могли стереть настройки роутера.

## [1.4.0] — 2026-10-04

### Добавлено
- Вкладка «Реклама»: карточка «Сайты без блокировки» — сайт и его поддомены не блокируются (исключение `@@||сайт^`). Рекламу с чужих доменов на этом сайте DNS-блокировка по-прежнему убирает.
- Там же список «Недавно заблокировано» (домен и устройство) с кнопкой «Разрешить» — чтобы быстро найти домен, без которого сломался сайт. Для него AdGuard Home хранит последние 1000 запросов только в памяти; команда `flint-adblock blocked`.

### Изменено
- Панель читает `/etc/xray/flint.env` напрямую; ссылка `/usr/share/flint/env` удаляется при деплое.
- Панель определяет действие по самому параметру запроса: скрытые поля `a=` убраны из всех форм, параметры читаются только в ветке своего действия.
- На вкладке «Серверы» ручные серверы при наличии подписки идут под заголовком «Заданные вручную», а не повторяют «Серверы».
- `flint-adblock` разбирает ответы AdGuard Home через `jsonfilter`, а не регулярными выражениями; установщик проверяет, что `jsonfilter` есть.
- Новый сценарий `tests/router/panel.sh`: вкладки панели и основные действия через `panel.cgi`. Сценарии больше не запускаются, если не удалось снять копию `/etc/xray` (раньше выход сценария мог её стереть).

## [1.3.0] — 2026-10-04

### Удалено
- `kit/upstream-access.sh`: доступ из сети основного роутера ставит деплой по `UPSTREAM_IF` / `UPSTREAM_NET` из `flint.env` (в скрипте сеть и интерфейс были прописаны жёстко). После смены сети — поправить `flint.env` и повторить деплой.

### Изменено
- Переход со старых версий комплекта (следы `gru-*`, разметка `#@` в `nodes.conf`) вынесен из `install.sh` в `kit/migrate.sh`, у каждой миграции указано, когда её можно удалить.
- Настройки dnsmasq и правила firewall ставятся одним `uci batch` вместо десятков отдельных `uci set`; итоговые настройки те же.
- Команды `flint-node` и `flint-custom` больше не используют `set -e`: ошибки записи файлов и перезапуска Xray проверяются явно и выдают понятное сообщение. `set -e` остался только в `install.sh`.

## [1.2.2] — 2026-10-04

### Изменено
- Список пользовательских файлов (`flint.env`, серверы, подписки, сайты, блокировка рекламы) задан один раз — в `kit/state-files`. Его читают деплой, бэкап, восстановление и установщик; раньше список был скопирован в семь мест.
- Бэкап забирает эти файлы одним архивом `backup/<дата>/state.tar.gz` (одно подключение вместо девяти) и распаковывает его в `config/`.
- `tests/run.ps1` / `tests/run.sh` сначала деплоят рабочую копию, поэтому все сценарии проверяют текущий код. У `deploy` появился ключ `-KeepKit` / `--keep-kit`.

## [1.2.1] — 2026-10-04

### Исправлено
- Повторный деплой больше не заменяет серверы подписок старой копией: `config/nodes.conf` — это только серверы, заданные вручную, а старый файл с группами `#@` не затирает уже существующие `nodes.d/<id>.conf`.
- Файл `nodes.d/<id>.conf` подписки, которой нет в списке (например, после восстановления), больше не работает «невидимкой»: такие серверы не используются, а файл удаляется при обновлении.
- `flint-custom del` завершался с ошибкой, если удалялся не текущий сервер.

### Удалено
- `tools/sub2nodes.py`: список серверов подписки собирает роутер, Python на компьютере не нужен.

### Изменено
- Раскладка файлов серверов и разбор их строк — в одном месте (`/usr/share/flint/lib.sh`), его используют `flint-node`, `flint-custom`, `flint-sub-update`, firewall и тесты.

### Добавлено
- Второй аудит качества кода и план исправлений: `docs/code-quality-audit-1.2.md`, `docs/refactoring-plan-1.2.md`.

## [1.2.0] — 2026-10-04

### Изменено
- Серверы каждой подписки хранятся в `/etc/xray/nodes.d/<id>.conf`, свои — в `nodes-custom.conf`, заданные вручную — в `nodes.conf`. Разметка `#@` в одном файле убрана.
- При установке старый `nodes.conf` с группами `#@` автоматически разбирается по файлам (копия остаётся как `nodes.conf.bak`).
- Бэкап, восстановление и деплой переносят каталог `nodes.d/`.

### Добавлено
- План и отчёт по качеству кода: `docs/code-quality-audit.md`, `docs/refactoring-plan.md`.

### Изменено

### Добавлено
- Проверочные сценарии на роутере: `tests/router/` и обёртки `tests/run.ps1` / `tests/run.sh` (режим без серверов, подписка, свой сервер, переключение при исчезновении текущего).

- Шапка панели: логотип слева, переключатель языка RU | EN и кнопка «Выйти» — в правом верхнем углу на компьютере и телефоне. На странице входа переключатель языка тоже вверху справа, версия — внизу под девизом.

- README: раздел «Где реклама останется», в английском — «Devices on the network»; скриншоты пересняты, добавлен экран «Без серверов».

### Исправлено
- Ссылки «Добавить подписку» и «Добавить свой сервер» в режиме без серверов почти не были видны на тёмном фоне — теперь это кнопки.

## [1.1.0] — 2026-10-03

### Добавлено
- Установка без серверов: для деплоя достаточно `config/flint.env` с `UI_PIN`, а `config/nodes.conf`, `SUB_URL` и `VLESS_UUID` необязательны. Пока серверов нет, Xray не запускается и устройства ходят в интернет напрямую; на вкладках «Статус» и «Серверы» есть ссылки «Добавить подписку» и «добавить свой сервер». Первая добавленная подписка или свой сервер включает VPN сам.
- Если задан `SUB_URL`, а серверов ещё нет, установка сразу скачивает серверы подписки.

### Изменено
- Последнюю подписку теперь можно удалить: роутер переходит в режим без серверов.
- «Скопировать и изменить» на вкладке «Свои серверы» скрыто, пока копировать нечего.

### Исправлено
- Удаление последнего своего сервера, когда он был текущим, больше не оставляет Xray со старым конфигом.

## [1.0.0] — 2026-10-03

### Добавлено
- Вкладка «Подписки»: несколько подписок от разных VPN-провайдеров (формат v2rayN / Happ / Hiddify — список `vless://`, обычный или base64). Подписку можно добавить по ссылке, сменить ей ссылку или название, удалить.
- Название подписки берётся из заголовка `profile-title`, срок действия и трафик — из `subscription-userinfo`; видны в списке подписок.
- Серверы на вкладке «Серверы» сгруппированы по подпискам, свои серверы — отдельной карточкой.
- Команды `flint-sub-update list | add | set | url | del`.
- Версии: файл `kit/VERSION`, версия внизу меню панели и на странице входа, `/usr/share/flint/version` на роутере; деплой пишет, какая версия ставится и какая стояла. Этот changelog.

### Изменено
- Обновление подписок и интервал автообновления переехали с вкладки «Серверы» на «Подписки»; «Обновить все подписки сейчас» обновляет все подписки сразу.
- Подписка, которая не скачалась, сохраняет свои прежние серверы; ошибка видна у этой подписки.
- `SUB_URL` из `flint.env` теперь только первая подписка на новом роутере; список подписок хранится в `/etc/xray/subscriptions` и попадает в бэкап (`config/subscriptions`).
- Повторный деплой не заменяет `nodes.conf` на роутере копией с компьютера, если на роутере есть подписки.
- Сайты всех подписок идут мимо VPN.

### Исправлено
- Установка не падает, если сервера `DEFAULT_NODE` нет в списке: включается первый сервер.
- Сообщения вида «3 серверов» заменены на «серверов: 3».

## [0.7.0] — 2026-10-03

### Изменено
- Проект переименован: префикс `gru-` заменён на `flint-` во всех скриптах, службах и путях (`flint-node`, `flint-adblock`, `/www/flint`, цепочка `FLINT_DNS`, переменная `FLINT_LANG`), файл настроек — `config/flint.env`.
- Упоминания провайдера убраны: проект работает с любой подпиской VLESS + REALITY.

### Добавлено
- `install.sh` переводит уже установленный роутер на новые имена: удаляет старые службы, файлы, cron-задания, правила firewall и цепочку `GRU_DNS`, переносит скачанные фильтры AdGuard.
- `restore` принимает бэкапы, сделанные до переименования (`gru.env`).

## [0.6.0] — 2026-10-03

### Добавлено
- Блокировка рекламы на уровне DNS — AdGuard Home из прошивки GL, отдельный экземпляр перед dnsmasq. Включается кнопкой на вкладке «Реклама».
- Списки фильтров: по умолчанию AdGuard DNS filter, готовые списки (HaGeZi, OISD, Steven Black и др.) и свои по ссылке; автообновление и «Обновить списки сейчас».
- Свои правила «Блокировать» / «Разрешить» в синтаксисе AdGuard.
- Устройства без блокировки (по MAC-адресу), выбор из подключённых устройств.
- Статистика за сутки; при сбое AdGuard Home watchdog перезапускает его, а если не помогло — DNS идёт напрямую в dnsmasq.

### Исправлено
- Установка не обрывается, если проверка VPN после смены сервера не дождалась ответа; финальная проверка делает три попытки.

## [0.3.0] — 2026-10-03
