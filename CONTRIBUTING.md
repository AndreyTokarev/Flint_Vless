# Участие в разработке

Спасибо, что хотите помочь. Здесь — то, без чего правку не примут, и то, что сэкономит вам время.

## Что приветствуется

- исправления ошибок в скриптах, панели и документации;
- поддержка других роутеров (сейчас проверено только на GL.iNet GL-BE6500) — приложите отчёт
  по шаблону «Роутер, на котором проверено»;
- переводы панели и документации;
- наблюдения о работе в вашей сети: что не проходит у провайдера, что помогло.

## Правила проекта

1. **POSIX shell.** Файлы `kit/**` — `#!/bin/sh`, без bash-измов. `set -e` допустим только в
   `kit/install.sh`; команды `flint-*` проверяют ошибки явно через `fail`.
2. **Одно место для понятия.** Пути и разбор серверов живут в `kit/files/usr/share/flint/lib.sh`.
   Пользовательские файлы состояния перечислены один раз — в `kit/state-files`; новый файл
   добавляйте туда, а не в каждый скрипт.
3. **Размер.** Файл не должен расти за 1000 строк. `panel.cgi` уже перешёл договорённый порог
   600–700 строк — правки, которые его увеличивают, лучше делать вместе с выносом части.
4. **Язык интерфейса.** Всё, что видит пользователь, — через `t "по-русски" "in English"`.
   Комментарии и шапки файлов — по-английски.
5. **Справка команд.** Блок `# Usage:` в шапке файла; печатается функцией `help` из `lib.sh`,
   номера строк не использовать.
6. **Переводы строк.** LF. В репозитории объявлено `* text=auto eol=lf`; CRLF в `kit/**`
   ломает разбор на роутере.

## Порядок работы над правкой

1. **Версия и запись.** Номер версии — в `kit/VERSION`, изменения — в `CHANGELOG.md`
   **и** `CHANGELOG.en.md` (формат [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
   версии по [SemVer](https://semver.org/lang/ru/)).
2. **Одна версия — один тег** `vX.Y.Z`. Несколько тегов на одном коммите не ставим.
3. **Если меняются команды, файлы или поведение** — правка README на **двух** языках
   (`README.md` и `README.en.md`).
4. **Проверка на роутере обязательна.** До коммита:
   ```sh
   ./deploy.sh            # или .\deploy.ps1
   ./tests/run.sh         # или .\tests\run.ps1
   ```
   Набор сценариев проверяет установку без серверов, повторный деплой, подписки, свои серверы,
   автопереключение и панель (более 180 проверок). Сценарии работают на живом роутере:
   большая часть проверок — это реальные `iptables`, DNS и запущенные службы.
5. **Миграции** — в `kit/migrate.sh`, с указанием в шапке, с какой версии её можно удалить.
6. **Секреты не коммитить.** Ссылки подписок, UUID, PIN и пароли Wi-Fi живут только в
   `config/` и `backup/` (оба в `.gitignore`). Перед публикацией проверьте:
   ```sh
   git grep --cached -nE 'vless://|sdns://[A-Za-z0-9_-]{20,}|UI_PIN=[A-Za-z0-9]{4,}'
   ```
